# 独立窗口公共组件

这份源码随三个独立 Mod 仓库同步分发，静态编入 ASI 和 Standalone。每个项目可独立构建和运行，不需要相邻仓库或额外加载程序。窗口布局、手柄导航和快捷键协作遵循同一套规则。

## 共同规则

- `ui.h` / `ui_shell.cpp`：固定 Aside、Header、Main、Footer。标题区域可拖动，位置在本次运行内保留，分辨率变化时夹回客户区。
- 三个调用方统一使用 20px 基础字体，缩放为 `clamp(客户区高度 / 1080, 0.7, 2.5)`，只设置 `FontScaleDpi`。布局自身已按该比例计算尺寸，不再调用 `ScaleAllSizes`；这样小分辨率仍保留边框和相同的控件留白。
- LB/RB 或 PgUp/PgDn 切侧栏；LT/RT 或 Ctrl+PgUp/PgDn 切顶部 Tab。十字键/左摇杆只在 Main 选择，右摇杆滚动当前容器并可继续滚动外层。
- A/Enter 确认或编辑，B/Esc 结束编辑或关闭。侧栏、顶部 Tab、关闭按钮和页脚不进入黄色焦点候选。
- `frame.controller` 表示最后活跃设备，不表示是否连接手柄；这样插着手柄仍可正常使用鼠标光标。
- 切出游戏保留只读窗口，取消待确认与输入武装。只有前台、健康渲染和本窗口拥有输入时才接管游戏操作。恢复后要求释放按键，停止渲染最多 500ms 后放行。
- Win32 后端须定义 `IMGUI_IMPL_WIN32_DISABLE_GAMEPAD`。`FeedGamepad` 只使用游戏原调用链的缓存样本，过期或失活时传 `nullptr`；不得主动再次轮询并提前消费单 View 回放。

## 多 ASI 共存

每个 IAT 入口先构造 `GamepadCall`，再调用原函数。全部合作内层先观察同一原始结果，只累计捕获/补发请求，最外层最后 `Filter`。共有 TLS 槽按当前进程隔离，避免其他 Mod 的面板打开后，本模块再也收不到打开组合。

`InputLease` 让一个窗口接管输入。显式打开另一窗口会转交所有权，旧窗口保留页面和位置后关闭。`PresentInstallGuard` 串行化各自 MinHook 的 Present/Resize 挂钩创建和启用，防止同时修改旧入口导致调用链丢失。协议不接管其他作者的非合作输入实现，也不保证任意挂钩组合均兼容。

## 独立快捷键

- `hotkeys.h` / `hotkeys.cpp`：每个 DLL 注册稳定动作 ID、中文动作名称和默认绑定。键盘由一个主键及 Ctrl/Alt/Shift 组成；手柄统一为 View 加一个数字按钮。修饰键和手柄数字按钮精确匹配，排除旧逻辑中附加修饰键也能触发的别名。
- `hotkeys_ui.cpp`：三个窗口复用相同的“选择动作 → 选择主键/修饰键/手柄按钮 → 保存”页面。未保存草稿不会生效，离页或失焦由调用方重置草稿。窗口入口必须保留键盘绑定；普通动作可取消绑定。
- 每个 Mod 的数据目录分别保存 `shortcuts.ini`，不写游戏设置或业务设置。格式为 UTF-8 的 `[Hotkeys]` 节，`Schema=1`；动作值按十进制 `主键,修饰位,手柄按钮位` 保存。用户应从界面修改，未知动作与其他节在保存时保留。
- 进程内的 `Sky2Standalone.Hotkeys.v1` 共享区仅包含固定大小数据。保存先检查所有已加载合作 DLL，预留候选绑定，释放共享锁后原子写入文件，再发布运行时快照。其他 DLL 同时检查已生效和预留绑定，因此并发保存也不能抢占同一组合。失败时保留旧绑定；恢复默认同样进行整组校验。
- 初始化冲突或损坏配置不自动覆盖文件。普通动作使用可用默认值或取消绑定；窗口动作优先恢复默认，必要时选用未占用的 Ctrl+Alt+Shift+功能键，并显示恢复提示。只检查当前已加载合作 Mod，无法自动读取游戏或其他作者 Mod 的自定义键位。
- 键盘与手柄分发读取本 DLL 的短锁快照；输入挂钩不得执行文件 I/O。revision 改变后清除旧事件，等待输入释放再武装，防止保存操作或按住的旧键触发新动作。业务快捷键仅在所有合作窗口关闭时执行，窗口入口可按现有所有权协议交接。

## 维护与验证

三个仓库内本目录应保持逐文件一致。`sky2_ui.h` 仅描述绘制帧和控件函数表 `Sky2UiApi`；业务页面显式接收当前上下文中的绘制接口，不提供动态 DLL 管理服务。共同控件、导航与输入协议的修改应同步到三份副本并运行回归。

独立项目设置 `SKY2_SOLO_IMGUI_TARGET` 后引入 `tests.cmake`。测试覆盖固定布局、焦点、滚动、拖动、失焦、共享 TLS 的嵌套输入链，以及真实配置文件和多 DLL 并发快捷键冲突。实际页面另外使用各项目的 WARP 合成预览；这些检查不等于实体设备和游戏内验收。
