# 多语言界面

队伍 Mod 跟随游戏的**文本语言**，支持简体中文、日语、英语、繁体中文、德语、法语、西班牙语和韩语。游戏语音、Steam 客户端语言和 Windows 显示语言不用于选择 Mod 界面语言。

## 文案与名称的来源

| 内容 | 来源 | 维护位置 |
| --- | --- | --- |
| 功能开关、操作结果、错误提示、快捷键说明 | Mod 自有八语翻译 | `native/ui_text.h` |
| 角色名称、原生队伍菜单术语 | 玩家安装的对应语言游戏资源 | `native/game_names.*` |
| 当前文本语言 | 经支持版本校验后的游戏设置，只读检测 | `native/game_language.*` |
| 字形 | 本机已安装字体，按实际字形覆盖检查 | `native/panel_fonts.*` |

原生名称直接读取对应语言的 `t_name`、`t_text`。资源读取失败时显示明确的本地化角色编号和提示，不用另一语言的姓名或人工翻译冒充游戏原文。仓库和发行包不附游戏文本表或游戏字库。

## 修改自有文案

1. 为一个独立语义增加 `Text` 编号，在 `kUiTexts` 相同位置提供完整八语条目。
2. 字段顺序为简中、日、英、繁中、德、法、西、韩，与 `Language` 枚举一致。不要按游戏内部语言编号排列。
3. 普通绘制使用 `Tr(Text::...)`；测试和离屏预览使用 `TextFor(language, id)`。两者都返回 UTF-8。
4. 状态服务保存语义编号，绘制时再取译文。不要在全局标签数组或消息缓冲区缓存已经翻译的文字。
5. 带参数的文字必须保持各语参数类型和顺序一致。新增格式同时更新 `tests/localization_text_tests.cpp` 的显式参数合同，不使用 `%n`、位置参数或未约定的格式。
6. 角色名称通过参数传入。涉及游戏术语时先核对对应语言资源，不根据其他语种或系列惯用译名猜测。

`Text::None` 是唯一允许八语全部为空的消息。非法文本编号返回空串；非法语言编号的防御性回退不代替八语完整性检查。

## 布局与验证

翻译长度不等于中文字数。面板应按实际文字宽度计算列宽，长说明允许换行，并为底部快捷键保留空间。控件身份使用稳定 ID，不以译文作为唯一标识；切换语言不能重置当前选择或误触发角色操作。

`tests/localization_text_tests.cpp` 不依赖游戏或 Windows，检查全部文案的八语完整性、UTF-8、格式参数、非法编号，以及已存在状态提示的语言切换。原生名称读取、语言编号映射、字体覆盖和面板布局由各自测试检查。

人工验证应覆盖八种游戏文本语言，特别检查：角色名与游戏一致；切换语言后旧提示同步变化；德语、法语等长文本与韩文字形完整；720p 下长提示和固定队员警示不遮挡操作；键盘和手柄提示热切换正常。
