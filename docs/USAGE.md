# 使用指南

[返回首页](../README.md) · [安装指南](INSTALLATION.md) · [测试与排错](TESTING.md)

本页描述当前源码的独立窗口；Standalone 与 ASI 的功能、界面和键位相同。已发布 **0.6.0** 附件仍采用原面板，历史操作见 [0.6.0 使用指南](https://github.com/blockshy/sky2-party-editor/blob/v0.6.0/docs/USAGE.md)。

## 界面语言

从游戏设置更改**文字语言**，面板会自动切换，无需单独配置 Mod。支持简体中文、繁体中文、日语、英语、德语、法语、西班牙语和韩语；仅更改语音语言不会改变面板文字。

角色名采用该语言游戏资源中的完整名称，原生菜单术语也从游戏表读取。读取失败时会提示并显示角色编号，不使用猜测的译名。切换语言只改变显示，保留当前选择及原有确认期限，不执行队伍修改。

字体从 Windows 已安装字库加载，不随 Mod 分发。若出现方框或缺字提示，请在 Windows 中安装对应语言的补充字体并重启游戏；无需更改 Windows 显示语言。

## 控制面板

默认按 **F8** 或 **View + 十字键左**显示/隐藏面板。默认 F8 不带修饰键，自定义组合则精确匹配所选 Ctrl、Alt、Shift，任何 Win 组合均不触发；手柄先按住 View 再按已选按钮，也支持同时按下，两种操作都须先完成松键。按下任何额外数字按钮（含斜方向）时不触发。

| 操作 | 键盘 / 鼠标 | Xbox 手柄 |
| --- | --- | --- |
| 选择内容控件 | 方向键，或点击 | 十字键 / 左摇杆 |
| 切换“队伍编辑 / 使用说明 / 快捷键”侧栏 | PgUp / PgDn，或点击 | LB / RB |
| 切换“功能设置 / 角色后备”页签 | Ctrl + PgUp / PgDn，或点击 | LT / RT |
| 切换开关 / 确认加入 | Enter，或点击 | A |
| 返回 / 关闭面板 | Esc，或“关闭”按钮 | B |
| 滚动内容 | 鼠标滚轮 | 右摇杆 |
| 移动窗口 | 拖动顶部标题 | — |

黄色焦点仅出现在 Main 内容的可操作控件，侧栏和页签使用各自的切换键。侧栏、标题、页签和底部提示保持固定，角色名单按可用高度调整。关闭面板后仍按住的按键会在松开后归还游戏。

切到其他应用时保留窗口位置和当前页，后台只读并取消角色确认；切回后先松开原按键再继续。渲染失败或超过 500 毫秒没有成功帧时，输入自动放行。打开另一个采用合作输入协议的独立 Mod 窗口时，旧窗口关闭，页面和位置保留。

多个独立 ASI 共用时应一起更新到采用合作输入协议的构建。输入只经过游戏已有 XInput 调用链，保留 Steam Input 映射；不另行轮询物理设备。未检测到样本时仍可用已设置的键盘快捷键和键鼠。原生编成页面继续使用游戏自身的按键与提示。

### 快捷键设置

在“快捷键”侧栏选择“队伍窗口”，通过选择器设置键盘主键、Ctrl / Alt / Shift 和手柄按钮，再保存。这里不录制真实按键，因此 LB/RB、LT/RT、Esc/B 仍按正常面板导航操作；离开栏目会撤销未保存的草稿。

- 保存检查同一 Mod 与其它已加载合作 Mod 的所有已登记动作。冲突显示占用模块和动作，保存被拒绝；“恢复默认”也不会抢占其它 Mod 的绑定。
- 队伍只有“打开 / 关闭窗口”这一项独立动作，必须保留非空键盘入口。手柄可清空，或设置 View 加一个 A/B/X/Y、十字键、肩键或摇杆按下按钮；方向轴、扳机、Start、单 View 均不能设置为全局绑定。
- 窗口内无 View 的方向、A/B、肩键、扳机和摇杆导航保持原用途。键盘不提供 Win、纯修饰键、导航主键和系统保留组合，例如 Alt+F4、Ctrl+Alt+Delete。
- 保存成功后立即切换生效值，并等待键盘/手柄松开；按住旧键、新键或先松修饰键都不会补触发。保存失败保留旧绑定并显示原因。

独立设置保存在本入口的数据目录 `Sky2PartyEditor/shortcuts.ini`（ASI 为 `plugins/Sky2PartyEditor/shortcuts.ini`），与功能 `settings.ini` 分开。未知节、未知键和注释会保留。文件缺失时使用默认值，显式保存才创建；手工修改需重启游戏。

启动遇到坏配置或冲突时先使用可用默认值；若窗口默认键也被占用，会尝试 **Ctrl+Alt+Shift+F1～F24** 中可用的组合（跳过系统保留组合）。实际入口同时显示在快捷键页，并写入同目录 `party.log` 的 `Window shortcut:` 提示，打不开窗口时先看日志。该恢复不会自动覆盖原文件。也可退出游戏，将 `shortcuts.ini` 改名保留后重启恢复默认，再检查另一个 Mod 的绑定。冲突范围限采用同版合作协议并已加载的 Mod；不声明能够识别所有第三方插件或原生游戏键位。

### 所有独立 Mod 窗口关闭时

以下是队伍插件仍会处理或放宽条件的入口；当前源码没有额外的全局功能开关、直接加入角色或确认快捷键。

| 输入 | 生效条件与行为 |
| --- | --- |
| 已配置键盘组合（默认 F8） | 游戏在前台，队伍面板已初始化且最近 500 毫秒内绘制成功；精确匹配修饰键且无 Win；新按主键时打开队伍窗口 |
| 已配置 View 组合（默认 View + 十字键左） | 满足前述前台与渲染条件，并由游戏已有 XInput 调用链提供有效样本；完成初装、重连或失焦后的松键，View 按住时新按已选按钮，且无额外数字按钮；打开队伍窗口 |
| 单按 View | 按住期间暂缓交给游戏；释放后仅补发一次游戏原操作。期间按过其它按钮、摇杆、扳机，或另一个 Mod 窗口占用过输入，则不补发 |
| 游戏原生“队伍 / 编成”操作 | “随处编成”已经在安全帧应用时，放宽普通探索入口；Xbox 默认是 X，键盘及重映射以游戏提示为准。普通主菜单复用同一个原生操作，仍核验当前队伍、菜单对象、状态稳定及剧情限制 |

单 View 与“队伍 / 编成”属于原生游戏操作。队伍插件没有为原生编成另设独立键盘快捷键，也不会把 A / Enter、B / Esc、LB/RB、LT/RT、左右摇杆等面板导航在关窗后当作业务命令。

当前独立队伍入口不再硬编码 F11 或 View + LS 别名，但可以在无冲突时自行配置。其它 Mod 的既有业务快捷键不由队伍插件删除，例如默认 Ctrl + F8 由宝箱插件处理。关闭窗口时尚未松开的按键会先经过松键保护，随后恢复正常游戏输入。

## 四项功能

| 开关 | 作用 |
| --- | --- |
| 解除固定队员 | 允许原生固定角色与可用后备交换；保留角色真实固定标记 |
| 随处编成 | 放宽地点和原生入口限制，在普通探索时可直接打开原生编成，也支持主菜单入口 |
| 暂不可选后备 | 允许选择原本已显示但暂时不能选取的后备 |
| 未入队角色（实验） | 在下方逐人确认加入或开放隐藏后备；缺少数据时按下一节规则补足 |

前三项默认开启，实验功能默认关闭。修改会在可自由行动、原生菜单关闭时应用，面板显示期望状态及等待状态。战斗、过场和换图期间需等待；剧情编成锁仍保留。

开启“随处编成”后，关闭面板，在探索画面按游戏原生队伍键即可编成。Xbox 默认键为 **X**，若更改过按键，请以游戏内提示为准。

本 Mod 不扩充四人主力上限，不永久锁定队伍，也不保证绕开后续剧情的重新编队。关闭功能只恢复对应限制，不自动撤销已完成的队伍或角色修改。

## 角色与数据补足

支持角色：

- 常规队员（简体中文名）：艾丝蒂尔、约书亚、雪拉扎德、奥利维尔、克萝赛、阿加特、缇妲、阵、凯文神父。
- 可战斗客串（简体中文名）：克鲁茨、亚妮拉丝、乔丝特、尤莉亚上尉、穆拉少校。

开启实验功能后，在普通探索选择角色并确认两次。更换项目、关闭面板、超时或场景/存档变化会取消第一次确认。加入后关闭面板，再使用原生编成换入主力。

| 面板操作 / 状态 | 含义 |
| --- | --- |
| 加入后备 | 角色数据完整，加入当前后备名单 |
| 开放后备 | 显示已存在但被隐藏的后备，不重复新增 |
| 补基础装备并加入 | 核心培养数据已存在，但缺少基础武器或战技；先补足再加入 |
| 数据未就绪 | 缺少可信核心培养记录，本版不会创建完整新角色 |
| 游戏队伍菜单中调整 | 已在可见名单，直接到原生页面换人 |

补足只处理缺失项：

- 空武器槽生成一件适配的基础武器，**不消耗背包**；已有武器、其他装备和回路保持不变。
- 全空战技栏按当前等级学习原生可学战技，不升级角色、不授予超等级战技、不清空已有列表。
- 若空列表仍保留合法的本人继承 S 战技选择，会恢复该项及选择，包括已核验的原有剧情 S 战技；不因此批量开放其他剧情技能。
- 不重放入队剧情，不补写剧情旗标，不创建尚未初始化的角色记录。支持名单中的角色并非在每份存档里都满足加入条件。

客串的装备与导力器能力以原生数据为准。加入后请检查装备、战技、S 战技及战斗表现，再决定是否保存。若出现部分补足提示，表示已经可能产生局部变化，**不代表完整回滚**；停止重复操作并保留日志，详见[问题反馈](TESTING.md#反馈问题)。

## 保存、关闭与卸载

游戏正常保存会保留队伍调整和补足的数据。关闭开关、退出游戏或卸载插件不会移除已加入的角色，也不会撤回基础武器或战技；要恢复修改前状态，请读取保留的原始存档。

固定成员换到后备后，原版限制可能使其不可见。面板会检查四支队伍并提示需换回主力的成员；仍存在此情况时拒绝关闭“解除固定队员”。**卸载前请按[恢复步骤](INSTALLATION.md#卸载前恢复固定队员)处理并保存**，不要直接删除插件来代替恢复。

## 配置

面板应用设置后会保存到对应数据目录的 `settings.ini`：独立版为 `Sky2PartyEditor/`，ASI 版为 `plugins/Sky2PartyEditor/`。安装和更新脚本保留该文件。

退出游戏后也可手动创建或编辑，手动更改需重启读取：

```ini
[Party]
Enabled=1
UnlockFixedMembers=1
AnywhereFormation=1
UnlockUnavailableMembers=1
AllowUnjoinedMembers=0
```

| 配置项 | 对应功能 |
| --- | --- |
| `Enabled` | 整个插件，包括面板；0 为禁用 |
| `UnlockFixedMembers` | 解除固定队员 |
| `AnywhereFormation` | 随处编成 |
| `UnlockUnavailableMembers` | 暂不可选后备 |
| `AllowUnjoinedMembers` | 未入队角色（实验），仍需逐人确认 |

0 为关闭，1 为开启。面板可在运行中切换后四项；缺失项使用上述默认值。直接离线关闭固定队员功能或 `Enabled` 不会执行面板中的恢复检查。
