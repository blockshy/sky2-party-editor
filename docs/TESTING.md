# 测试与排错

[返回首页](../README.md) · [安装指南](INSTALLATION.md) · [使用指南](USAGE.md)

本页适用于 **0.5.0**。先保留独立存档，再验证功能；自动检查与成功加载不能代替角色战斗、剧情及存取档检查。

## 没有面板时

1. 确认安装的是发行包而非 Source code，并按[安装结构](INSTALLATION.md#手动安装)核对文件，没有额外的 dist 层级，也没有同时放入两种队伍入口。
2. 进入普通探索，先试 F11。ASI 版须先有可正常加载插件的 Ultimate ASI Loader；公共 Loader 与其他 Mod 的同名 DLL 不能互相覆盖。
3. 检查对应数据目录的 `party.log`：独立版位于 `Sky2PartyEditor/`，ASI 版位于 `plugins/Sky2PartyEditor/`。若记录版本不支持，核对[游戏 EXE 哈希](INSTALLATION.md#兼容版本)，不要跳过验证。
4. 核对 `settings.ini` 中 `Enabled` 没有设为 0。手动编辑设置后需要重启。
5. 若 F11 可用而手柄入口不可用，按面板提示用键盘操作，并记录手柄、Steam Input 设置和同时安装的 Mod，供兼容性排查。

## 面板与输入回归

| 检查 | 预期 |
| --- | --- |
| F11 与 View + LS 各开关两次 | 每次按下只切换一次，没有 Xbox 弹窗 |
| 方向键 / 十字键、Enter / A、Esc / B | 选择、确认和关闭正确，面板内不同时操作游戏 |
| 鼠标停在一行，改用键盘/手柄选择其他行或滚动 | 仅当前选中项目显示绿色条 |
| 组合键先后释放、关闭时仍按住确认键 | 不重复切换，关闭后剩余按压不误触游戏 |
| 键盘与手柄交替、手柄断开重连 | 提示随输入切换，重连后可再次操作 |
| 按住鼠标后用 F11 关闭，再释放并重开 | 无残留按下、拖动或自动点击 |

ASI 与宝箱插件共用时，分别打开两个面板，关闭队伍面板后再操作宝箱清单、暂停与传送。确认两个插件都持续工作，短按 View 保持原功能。其他 Loader/插件组合需独立验证。

## 功能回归

1. 在普通探索逐项关闭、开启前三项。检查协会外原生队伍键入口、固定成员互换及暂不可选后备；关闭功能后应恢复对应限制。
2. 在原生菜单中提交设置，关闭菜单返回探索后检查是否应用。战斗、过场、换图时不得执行角色加入；剧情编成锁仍应限制操作。
3. 退出重启，核对开关保留。关闭开关不应自动改回之前的队伍。
4. 开启实验功能，确认角色一次后换行或关闭面板，应取消加入；同一项目再次确认两次才执行。
5. 分别检查完整数据角色、隐藏后备、缺少武器/战技角色和未初始化角色。未初始化角色应保持不可加入，已有可见成员不得重复新增。
6. 加入后通过原生编成换入主力，检查等级、装备、回路、普通战技及 S 战技，再验证跟随、换图、普通战斗与结算。主力不超过四人，已有角色不应被自动移除。
7. 将结果另存后读取，核对队伍和培养；再读修改前存档，确认不会自动重做上次加入。

继承档还应检查“空战技列表但保留 S 战技选择”的角色：补足后原有 S 战技应可用，已有等级、经验、装备和回路应保持。乔丝特的原有剧情 S 战技也需单独核对，不能只根据头像出现判断角色已完整可用。

## 卸载回归

用独立存档把固定成员换到后备，面板应提示角色及所属队伍，此时关闭“解除固定队员”应被拒绝。通过原生编成换回主力后，再关闭开关并保存；退出卸载，重新读档检查原版可见性。完整恢复方法见[卸载前恢复](INSTALLATION.md#卸载前恢复固定队员)。

独立版和 ASI 版应分别检查：手动安装后脚本卸载、脚本安装后手动卸载、同分发更新，以及按说明切换分发。未知同名文件应拒绝覆盖/删除，自己的配置、日志与其他插件应保留。安装自动测试只在临时目录执行，不应拿真实游戏目录试破坏性边界。

## 反馈问题

通过 [GitHub Issues](https://github.com/blockshy/sky2-party-editor/issues) 提供：

- Mod 版本、Standalone 或 ASI、游戏 EXE 哈希；ASI 另附 Loader 及其他插件版本。
- 键盘/手柄类型、Steam Input 是否启用、实际按键与最小复现步骤。
- 章节、地点、角色及原状态，问题发生在探索、菜单、战斗还是存取档环节。
- 面板提示截图及 `party.log` 中相关片段；公开前删除个人路径等信息。

若提示“数据已部分补足”，停止对该角色重复尝试；该提示不代表回滚。日志的 `Roster preparation` 记录包含角色、阶段及是否开始原生处理，可帮助区分学习、继承 S 技恢复和装备环节。优先读取原始存档继续游戏。

不需要公开完整存档、游戏资源或内存转储。提交开发改动时，自动测试方法见[构建指南](https://github.com/blockshy/sky2-party-editor/blob/main/docs/BUILDING.md#测试)。
