# Sky2 Party Editor · Hub 模块版

HubModule 是第三种可选分发。原 **Standalone** 和 **ASI** 持续保留，原键位、安装器和单独运行方式不变。三个分发使用相同队伍业务服务，同一游戏安装只启用其中一种队伍入口。

公共中心仓库：[Sky2 Mod Hub](https://github.com/blockshy/sky2-mod-hub)。[Hub 0.5.0 发行页](https://github.com/blockshy/sky2-mod-hub/releases/tag/v0.5.0)提供 `Sky2ModHub-0.5.0-Windows-x64.zip`，包含宿主和宝箱、高亮、队伍三个模块，不含公共 Loader 或各 Mod 原 ASI / Standalone。队伍仓库的原 0.6.0 Release 附件保持不变，本次源码接入不另建队伍 Release。

## 安装与切换

需要兼容 ABI 1 的 **Sky2 Mod Hub**。本包不附带公共 Loader 或 Hub，使用 Hub 的安装工具进行冲突检查、备份和安装。包内 `dist/` 对应游戏根目录：

- `plugins/Sky2ModHub/modules/Sky2PartyEditor.module.dll`
- `plugins/Sky2ModHub/modules/Sky2PartyEditor.module.ini`
- `plugins/Sky2ModHub/licenses/Sky2PartyEditor-LICENSES.txt`

清单使用 `Id=party`、`Abi=1`、`Enabled=1`。模块复用 `plugins/Sky2PartyEditor/settings.ini` 和日志目录，不复制、不移动、不覆盖已有玩家配置。Standalone 原有根目录设置如需迁移，应在关闭游戏后先备份，再通过宿主迁移流程处理。

切换前退出游戏；不要同时保留处于启用状态的原 `plugins/Sky2PartyEditor.asi`。独立版 `xinput1_4.dll` 也不能与其模块版同时加载；宿主负责识别入口冲突，模块继续使用原有命名互斥保护防止业务重复初始化。

安装 Hub 整合包时按宿主 README 执行检查、备份、安装及需要时的回滚；队伍旧版的 `Install-Mod.ps1` / `Uninstall-Mod.ps1` 不管理模块目录。保留现有配置，不通过删除数据目录解决入口冲突。需要更新 DLL、从模块切回原入口或彻底卸载时，仍须先恢复固定队员并退出游戏。模块包本身不含自动安装器。

## 使用

用 Hub 的统一快捷键打开中心，再进入“队伍编辑”。模块不占用独立 F11 / View + LS，不创建独立面板或采样手柄。键鼠/手柄导航、绑定管理和常用动作由宿主负责。

Hub 0.5.0 默认 F11 或 View + LS（按下左摇杆）开关中心。方向键 / 十字键 / 左摇杆选择，Enter / A 确认或进入编辑，Esc / B 返回；PgUp / PgDn 或 LB / RB 切换一级页面，Ctrl + PgUp / PgDn 或 LT / RT 切换页内标签。右摇杆滚动当前内容，鼠标可直接点击和滚动。失焦时保留只读页面并取消角色确认，切回游戏后继续操作。

Hub 页面提供“功能设置”和“角色后备”两个页内标签：四个开关分别显示实际生效状态与待处理请求；角色列表和所选角色操作在宽屏并排、窄屏纵排。打开队伍页动作默认进入功能设置，角色后备动作直接进入角色页。切换标签会取消待确认操作。加入与补足的持久化提示始终放在确认按钮旁，详细操作说明可以展开。颜色、卡片和状态提示使用宿主主题，新增文案覆盖八种语言。旧版 ABI 1 宿主没有布局扩展时使用普通按钮切页和纵向布局。

支持固定页头的新宿主将页面标题、简介和标签栏留在 Header，仅 Main 内容区滚动。角色名单随 Main 可视高度伸缩；窄窗口保留所选角色操作的空间。缺少 Header 或尺寸接口的旧宿主仍显示原内联标签和原列表高度，二次确认规则不变。

提供六个可绑定动作：打开队伍页、切换四个功能、打开角色后备页。角色后备动作只打开页面，**不直接加入角色，也不会预先完成第一次确认**。选择角色后必须在页面确认两次；切换角色、切页、关窗、失焦、超过 8 秒或场景/存档变化均取消确认。

### Hub 默认动作绑定

以下为 Hub 0.5.0 初次分配的默认值；动作快捷键在中心关闭时生效。已有自定义绑定优先，冲突项不会强行覆盖，实际按键以“快捷键”页为准。可以自行改键、清除或加入首页常用。

| 动作 | 稳定 ID | 键盘 | Xbox 手柄 |
| --- | --- | --- | --- |
| 打开功能设置 | `party.open` | Ctrl + Shift + F1 | View + 十字键右 |
| 切换解除固定队员 | `party.toggle_fixed` | Ctrl + Shift + F2 | 未分配 |
| 切换随处编成 | `party.toggle_anywhere` | Ctrl + Shift + F3 | 未分配 |
| 切换暂不可选后备 | `party.toggle_unavailable` | Ctrl + Shift + F4 | 未分配 |
| 切换未入队角色功能 | `party.toggle_unjoined` | Ctrl + Shift + F5 | 未分配 |
| 打开角色后备页 | `party.roster` | Ctrl + Shift + F6 | View + RS（按下右摇杆） |

完整默认集合和冲突规则由 [Hub 快捷键说明](https://github.com/blockshy/sky2-mod-hub/blob/main/docs/DEFAULT_BINDINGS.md)维护。“切换未入队角色功能”只改变许可开关，加入角色仍须在页面完成两次确认。

功能设置继续在普通探索、原生菜单关闭时执行。固定队员仍在后备时，关闭“解除固定队员”会被既有安全检查拒绝；中心显示对应原因。角色加入、装备/战技补足继续由游戏线程复核，页面只提交请求。

正常保存会保留队伍和补足变化。关闭模块或卸载不会撤销这些变化；基础数据补足遇到后续失败时可能存在部分变化。卸载前需要将固定队员换回主力并保存，规则与原 ASI 版一致。

## 实时启用与停用

支持生命周期扩展的 Hub 可在“模块与诊断”中实时停用、再启用队伍模块。停用请求会立即取消界面确认、作废尚未消费的加入请求，并阻止新请求；已经进入原生加入或补足的操作先正常收尾。模块随后等待普通探索的安全游戏帧，把本实例拥有的 15 处代码操作数恢复原值，并关闭原生菜单扩展。只有恢复成功才显示“已停用”。

- 原生菜单、战斗、过场或缺少可用游戏对象时显示等待，不在 Present 线程强行修改。
- 固定队员仍在后备，或无法完整核实四支队伍时拒绝停用。按提示在游戏编成中换回主力后，再次明确请求停用。
- 其他修改器改过相关代码、字节事务失败或状态未知时保留真实状态并说明失败，不报告“安全停用”。
- 停用不把四个功能偏好写成全关；重新启用在安全帧恢复原偏好，旧的加入请求不会复活。
- DLL、命名互斥、协调器和跳板保留在进程中；停用后的协调器仅转发原生调用。运行中不能替换 DLL 文件，更新文件仍须退出游戏。

旧版 ABI 1 宿主仍可使用模块原有功能；实时启停和首页开关状态是可选接口。旧版宿主没有实时管理能力时，继续使用重启加载设置。

原配置 `[Party] Enabled=0` 仍表示拒绝业务初始化，需要退出游戏后改回 `1` 并重启；平时的实时启停请使用 Hub“模块与诊断”。队伍模块过渡中不接受相反请求，先等待安全帧结果；模块自己的功能偏好与宿主的加载偏好分别保存。

## 开发与验证

构建当前模块需要 Hub **0.5.0 或更新的 SDK**；与旧 ABI 1 宿主的运行兼容不代表可以用缺少可选接口声明的旧 SDK 编译。相邻 `sky2-mod-hub/sdk` 存在时，Windows x64/MSVC 默认额外构建 `Sky2PartyEditorModule`。使用 `PARTY_HUB_SDK_DIR` 指定其他 SDK 路径，或 `PARTY_BUILD_HUB_MODULE=OFF` 仅构建原两版。模块不链接私有 ImGui/MinHook，UI 和挂钩通过宿主函数表调用。

新增测试覆盖生产页面的二次确认、切页/失焦/超时/世代失效、功能请求边界及语言转换；真实 DLL 测试检查 ABI、模块身份、可选尾部及不支持宿主拒绝路径。协调器回归检查安全帧启停、固定后备拒绝、在途请求等待、偏好保留与失败回退；名单服务使用私有合成对象检查停用取消队列和重新启用不复活旧请求。原业务、输入、图形链和安装回归继续保留。完整游戏内导航、原生编成、实机启停及存取档仍需实际游戏检查。

打包命令（开发者终端）：

```powershell
# 模块包使用宿主安装工具；不把原双分发安装器复制到新分发。
pwsh -NoProfile -File .\tools\Package-Mod.ps1 `
  -Distribution HubModule -BinaryPath .\build-hub-module\Sky2PartyEditor.module.dll
```
